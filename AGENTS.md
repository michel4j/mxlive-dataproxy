## Agent skills

### Issue tracker
GitHub Issues in this repo, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels
Using the default canonical triage vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs
Single-context repo layout: one root `CONTEXT.md` and `docs/adr/` for ADRs. See `docs/agents/domain.md`.
